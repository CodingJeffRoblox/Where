# Where 0.4.0 — a proper start, and downloads that just run

**Find what you're looking for.** Where connects your projects, tasks, notes,
saved links and files in one private, offline search.

This release is about the first minute with Where: getting it onto your
computer and opening it.

## ✨ What's new

### A loading screen that tells you what's happening
Where now opens instantly with an animated logo, a light circling it, a
progress bar and each step as it happens — *Finding your library…*,
*Starting the search engine…*, *Connecting your browser…* — then fades
into the app. It follows your light or dark theme, and if something goes
wrong it tells you right there.

### Real installers
- **Windows:** `Where-Setup-0.4.0-windows-x64.exe` installs Where for your
  user (no admin prompt), adds it to the Start menu (desktop icon optional),
  registers an uninstaller and opens Where when it's done.
- **Linux:** a single-file **AppImage** that runs on most distributions, and
  a **.deb** for Ubuntu, Debian and Mint that adds Where to your menu and a
  `where` command. Both for Intel/AMD and ARM.
- **Mac:** a universal `.dmg` for Apple Silicon and Intel.

### Starts on more PCs
The Windows downloads now include the Microsoft C++ runtime, so Where opens
even on computers without the Visual C++ Redistributable.

## 📦 Which file do I need?

| Your computer | Download | Then |
|---|---|---|
| **Windows** 10 / 11 | `Where-Setup-0.4.0-windows-x64.exe` | Run it |
| Windows, no install | `Where-0.4.0-windows-x64-portable.zip` | Unzip, run `Where.exe` |
| **Mac** (Apple Silicon or Intel) | `Where-0.4.0-macos-universal.dmg` | Drag Where to Applications |
| **Linux** (any distro) | `Where-0.4.0-linux-x64.AppImage` | `chmod +x` it, then run it |
| Ubuntu / Debian / Mint | `Where-0.4.0-linux-x64.deb` | `sudo apt install ./Where-0.4.0-linux-x64.deb` |
| Linux on ARM | `…-linux-arm64.AppImage` or `.deb` | Same as above |
| Chrome / Edge / Brave | `Where-0.4.0-browser-extension.zip` | See **Settings → Browser** in Where |

## ⚠️ First launch
These builds aren't code-signed yet, so your computer will ask once:
- **Windows:** *Windows protected your PC* → **More info → Run anyway**.
- **Mac:** right-click Where → **Open** → **Open**.
- **Linux AppImage:** make it runnable first (`chmod +x`). On Ubuntu 22.04+
  you may need `sudo apt install libfuse2`.

## 🔒 Still private by default
No account, no cloud, no telemetry, no AI. Your data stays in one file on
your computer. Uninstalling keeps it; delete it from Settings → Privacy's
folder if you want it gone.

## Known limitations
- File *contents* aren't searched yet — names, paths and types only.
- Phones (Android, iPhone) aren't supported yet.
- Unsigned builds (see *First launch*).
